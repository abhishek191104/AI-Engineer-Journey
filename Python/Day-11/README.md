## Mini-Project: Student Data Statistics Analyzer

### Description

A Python program that reads student marks from a CSV file and calculates descriptive statistics to summarize student performance.

### Features

* Reads student records using Pandas
* Calculates mean, median, and mode
* Calculates population variance and standard deviation
* Finds minimum and maximum marks
* Calculates percentiles
* Identifies students scoring above the mean

### Technologies Used

* Python
* Pandas
* CSV

## How to Run

1. Install Pandas: `pip install pandas`
2. Keep `student_marks.csv` and `day11_statistics_analyzer.py` in the same folder.
3. Run: `python day11_statistics_analyzer.py`
