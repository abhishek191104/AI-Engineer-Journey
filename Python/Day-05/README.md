## Important Concepts

### Class

A class is a blueprint for creating objects.

### Object

An object is an instance of a class.

### Constructor

`__init__()` is used to initialize object attributes.

### Inheritance

Inheritance allows one class to reuse functionality from another class.

### Method Overriding

A child class can provide its own implementation of a method inherited from a parent class.
